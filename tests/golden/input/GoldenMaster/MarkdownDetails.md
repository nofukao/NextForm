---
title: 折りたたみの検証
---

折りたたみ (`:::details`) の出力を固定するページ。

:::details 閉じて出る
中身は **Markdown** として変換される。

- 箇条書きも書ける
:::

:::details+ プラスで開いて出る
`+` は wiki の折りたたみボタンの見た目に合わせたもの。
:::

:::details open openでも開いて出る
`open` は HTML の属性名。どちらを覚えていても書ける。
:::

:::details+ open で始まるラベル
`+` を使えば `open` で始まるラベルも書ける。
:::

:::details
ラベルを省くと既定の語が入る。
:::

::::details 外側
:::details 内側
外側のコロンを増やすと入れ子になる。
:::
::::

:::details コードブロックの中の :::
```
:::
```
ここで閉じてはいけない。
:::

:::note 注意
`details` 以外は折りたたみにならず、そのまま文字として出る。
:::
