---
title: 箇条書きの間隔の検証
---

CommonMark の tight / loose と、その HTML の形を固定するページ。

種別 Markdown では、**空行は箇条書きを切らない**。項目のあいだに空行が
1 つでもあると、そのリスト全体が loose になり、離れた位置にある項目も
含めて**全項目**の中身が `<p>` で包まれる。これは仕様どおりで、直すべき
ものではない。ここではその HTML の形を記録して、うっかりパーサ側で
`<p>` を剥がす変更が入らないようにする。

見た目の側 — 空行を入れても間隔が変わって見えないようにする方 — は
`common/style/.markdown.css` が `li > *` の上下の余白を打ち消して受け持つ。
CSS の側は tests/css-rules.sh で見る。

## 空行なし (tight)

- ひとつめ
- ふたつめ
- みっつめ

## 空行あり (loose)

- ひとつめ
- ふたつめ

- みっつめ
- よっつめ

## 番号つきでも同じ

1. ひとつめ
2. ふたつめ

3. みっつめ

## 項目の中が複数段落

- ひとつめの段落。

  ふたつめの段落。同じ項目の中なので、ここの間は空けたままにする。

- 次の項目。

## 入れ子

- 親

  - 子
  - 子

- 親

## 記号を変えるとリストが分かれる

空行では分かれない。記号を変えると別のリストになる。

- ハイフンのリスト

* アスタリスクのリスト
