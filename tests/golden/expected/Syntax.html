    )

    長い行が折り返されること。横スクロールにならないこと。 

    ssh -R 12345:localhost:22 user@example.com -L 8080:internal.example.local:80 -N -f -o ServerAliveInterval=30
https://example.com/very/long/path/without/any/space/aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa

    ) — 言語指定なし


    function example($argument) { return "test"; }

    コード表示 (

    ) — 言語指定あり


    function example($argument) { return "test"; }
