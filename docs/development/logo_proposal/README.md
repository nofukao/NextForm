# ロゴ候補 (2026-08-18)

v0.5 のテーマ作業に合わせて、上流 ToraToraWiki の猫のロゴを NextForm 自身の
マークに置き換えるために描いた案。**採用したのは `e-cards`**。

`index.html` をブラウザで開くと、96px / 40px (ヘッダー実寸) / 16px (favicon) /
暗い地、および 6 色調それぞれの「見出しの色」に乗せた実寸で並べて比べられる。

| ファイル | 案 | 意味 |
|---|---|---|
| `a-monogram.svg` | NF モノグラム | N と F を線で組む。字なので意味が一意 |
| `b-form.svg` | フォームと次へ | 入力欄 + 右へのシェブロン。名前をそのまま絵にした |
| `c-morph.svg` | 変わる形 | 四角 → 角丸 → 円。字を使わない |
| `d-page.svg` | ページと矢印 | 角の折れた文書 + 矢印 |
| **`e-cards.svg`** | **重なるカード** | **ページが積み重なる。集積としての wiki。採用** |
| `f-prompt.svg` | プロンプト | `>` と入力の下線。線が最少で 16px に強い |

## 描き方の決めごと

- **手描きの SVG**。この開発環境には画像変換ツール (ImageMagick / rsvg /
  cairosvg / Pillow) が無い。ロゴ設定は `svg` を受け付けるので変換も要らない。
- インクは `#23282c`、差し色は `#d2603a`。色調 6 種の「見出しの色」は
  どれも明るいので、濃いインクならヘッダー上でどの色調でも読める。
- ヘッダーでの表示は最大 40px 角 (`THEME_HEADER_HEIGHT_MIN`)、
  favicon は 16px。**16px で形が残ること**を条件に選んだ。
- 文字を含む案 (`a-monogram`) 以外は言語に依らない。

## 採用後の配置

`e-cards.svg` は各テーマの `image/logo.svg` として入り、既定値もこれになる。
既存サイトは `THEME_IMAGE_LOGO` に `image/logo.png` を保存済みなので、
同じマークを描いた `logo.png` と `favicon.ico` も差し替える
(生成は `deploy/scripts/gen-logo.py`)。
